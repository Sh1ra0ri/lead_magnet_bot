# Lead Magnet Bot

Telegram-бот, который по команде `/start` присылает пользователю лид-магнит (набор сообщений: текст, фото, видео, документ, аудио, голосовые). Управление лид-магнитами — через админ-панель прямо в боте.

---

## 1. Установка и первый запуск

### 1.1 Зависимости
```bash
pip install -r requirements.txt
```

### 1.2 База данных
Нужен запущенный PostgreSQL. Проще всего локально через Docker:
```bash
docker run -d --name lm_postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=leadmagnet -p 5432:5432 postgres
```

### 1.3 Настройка `.env`
В корне проекта создать файл `.env` (по образцу `.env.example`):
```
BOT_TOKEN=токен_от_BotFather
DB_DSN=postgresql://postgres:postgres@localhost:5432/leadmagnet
SUPER_ADMIN_ID=твой_telegram_id
```

- **BOT_TOKEN** — получить у [@BotFather](https://t.me/BotFather): `/newbot` → следовать инструкциям → скопировать токен.
- **DB_DSN** — строка подключения к Postgres (поменяй host/порт/пароль/имя базы под свою настройку).
- **SUPER_ADMIN_ID** — твой числовой ID в Telegram (не username!). Узнать можно через [@userinfobot](https://t.me/userinfobot) — просто напиши ему `/start`.

Таблицы в базе создаются автоматически при первом запуске — ничего руками накатывать не нужно.

### 1.4 Запуск
```bash
python -m bot.main
```
Если в консоли появились логи и нет ошибок — бот запущен и слушает Telegram.

### 1.5 Остановка
- В том же терминале — `Ctrl+C`.
- Если бот запущен в фоне: `ps aux | grep bot.main`, затем `kill <PID>`.
- Если через Docker: `docker compose down` (или `docker stop <имя_контейнера>`).

## 2. Как пользоваться ботом

### 2.1 Обычный пользователь
Пишет боту `/start` — получает все сообщения активных лид-магнитов по очереди. Если ни один лид-магнит не активен, придёт сообщение "Лид-магнит пока не настроен."

### 2.2 Админ-панель
Команда `/admin` доступна только тем, чей Telegram ID есть в таблице админов (первым туда автоматически попадает `SUPER_ADMIN_ID` из `.env`).

Открывается меню:
- **📋 Список лид-магнитов** — все созданные лид-магниты, у активных стоит ✅
- **➕ Добавить лид-магнит**
- **👥 Администраторы** — управление списком админов

---

## 3. Создание лид-магнита

1. `/admin` → **➕ Добавить лид-магнит**
2. Ввести название (произвольный текст, пользователю не показывается)
3. Выбрать тип первого сообщения: `text`, `photo`, `video`, `document`, `audio`, `voice`
4. Отправить контент:
   - для `text` — просто текст
   - для `photo`/`video`/`document`/`audio` — **прикрепить файл и сразу написать подпись** (caption) под ним, одним сообщением в Telegram. Подпись сохранится как текст и будет показываться вместе с файлом — то есть картинка и текст придут пользователю единым сообщением.
   - для `voice` — просто голосовое (подписи Telegram к голосовым не поддерживает)
5. При желании добавить кнопку-ссылку: "Да" → ввести текст кнопки → ввести URL
6. Бот спросит "Добавить ещё одно?" — можно добавлять сколько угодно сообщений подряд, они будут показываться в том порядке, в котором добавлены
7. "Нет" → лид-магнит сохранён

---

## 4. Активация / деактивация

- Активных лид-магнитов может быть **несколько одновременно** — все активные будут отправляться пользователю при `/start`, один за другим.
- `/admin` → **📋 Список лид-магнитов** → выбрать лид-магнит → **✅ Сделать активным**
- Чтобы убрать из показа: открыть тот же лид-магнит → **❌ Деактивировать**
- Удаление лид-магнита (**🗑 Удалить**) стирает его вместе со всеми сообщениями безвозвратно (спросит подтверждение).

---

## 5. Редактирование сообщений лид-магнита

`/admin` → лид-магнит → **✏️ Сообщения**:
- список всех сообщений с номером и типом
- **❌** рядом с сообщением — удалить конкретное сообщение
- **➕ Добавить сообщение** — добавить ещё одно в конец (тот же флоу, что при создании)

Отдельного редактирования текста уже добавленного сообщения нет — если нужно поменять текст, удали сообщение и добавь заново.

---

## 6. Администраторы

`/admin` → **👥 Администраторы**:
- список текущих админов (Telegram ID)
- **➕ Добавить админа** — ввести Telegram ID нового админа (узнать можно через [@userinfobot](https://t.me/userinfobot))
- **🗑** рядом с ID — убрать админа

---

## 7. Частые проблемы

| Проблема | Решение |
|---|---|
| `/admin` не отвечает / нет доступа | Проверь, что твой Telegram ID совпадает с `SUPER_ADMIN_ID` в `.env`, и бот был перезапущен после правки `.env` |
| Ошибка подключения к БД при старте | Проверь, что Postgres запущен и `DB_DSN` в `.env` указывает на правильный host/порт/пароль |
| `/start` пишет "Лид-магнит пока не настроен" | Ни один лид-магнит не активирован — зайди в `/admin` → список → активируй нужный |
| Фото пришло без текста | Текст (подпись) нужно писать **вместе** с фото при отправке в Telegram, а не отдельным сообщением после |
